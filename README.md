# Relay app

The phone app for Relay, a smart ring. It is a Flutter app; the code has not been started yet.

## Start it

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. From this folder, run `flutter create --project-name relay_app .`
3. Run it with `flutter run`.

This repository is a copy of the app folder of the Relay ring's private project, updated on each published change. Changes made here directly are overwritten.
